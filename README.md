# 📌 Overview

Image Vault provides a secure and user-friendly platform for encoding, protecting, storing, and decoding hidden communication through images with a clean cybersecurity-themed interface.

The system combines:
- AES Encryption
- Image Steganography
- Password Protection
- Secure Vault Management

to ensure safe digital communication.

# 🧠 How It Works

1. Upload a cover image  
2. Enter confidential message  
3. Add encryption password  
4. Encrypt the message using AES encryption  
5. Hide encrypted data using LSB steganography  
6. Generate secured encoded image  
7. Download secured image  
8. Decode later using correct password

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Sirivennela310505/Image-Vault.git
````

## Navigate to Project Folder

```bash
cd Image-Vault
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
