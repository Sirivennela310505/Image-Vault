# 🔐 Image Vault

Image Vault is a modern cybersecurity-based image steganography application that allows users to securely hide confidential messages inside images using AES encryption and LSB (Least Significant Bit) steganography techniques.

The application provides a secure platform for encoding, protecting, storing, and decoding hidden communication through images with a clean and professional user interface.

---

# 🚀 Features

## 🔒 Secure Message Encoding
- Hide secret messages inside images
- Protect confidential communication
- Secure image-based data transfer

## 🛡 AES Encryption
- Encrypts messages before hiding them
- Adds an additional security layer
- Password-protected communication

## 🖼 Image Steganography
- Uses LSB (Least Significant Bit) technique
- Embeds encrypted data inside image pixels
- Maintains image visual quality

## 🔓 Decode Hidden Messages
- Extract hidden messages from secured images
- Requires correct password for decoding
- Secure retrieval system

## 🗄 Secure Vault System
- Store encoded images locally
- Manage secured communication files
- Organized image storage module

## 📊 Dashboard Analytics
- Track encoding and decoding activity
- Monitor stored images
- Security operation overview

## 📏 Image Capacity Detection
- Calculates message storage capacity
- Prevents oversized hidden messages
- Real-time message length checking

## 🔑 Password Protection
- Password strength indicator
- Secure access system
- Protected hidden communication

## 📥 Download Secured Images
- Generate encoded images
- Download secured output instantly
- Share encoded images safely

## 🎨 Modern Cybersecurity UI
- Responsive professional interface
- Dark-themed secure dashboard design
- Smooth animations and transitions

---

# 🧠 How It Works

1. Upload an image
2. Enter confidential message
3. Add encryption password
4. Encrypt the message
5. Hide encrypted data inside image
6. Download secured image
7. Decode later using password
